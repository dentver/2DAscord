# Changelog

## alpha 0.4 (2026-07-25)

### Добавлено
- Голосовая связь — VoiceEngine (sounddevice), VoiceController, VoiceProtocol (UDP), JitterBuffer
- Самоподписанный TLS-сертификат на основе RSA-2048 (cryptography) — всё P2P-соединение шифрованное
- Новые сигналы: `external_ip_ready`, `participant_avatar_updated`, `participant_name_updated`, `voice_state_changed`
- Новые команды протокола: `AVATAR`, `NAME`, `VOICE_PORT`, `VOICE_READY`, `PING`
- Heartbeat — хост шлёт PING каждые 45 секунд, чтобы держать TCP живым
- Системные уведомления (всплывающие в центре экрана на 3 секунды)
- Кликабельные метки (код сессии, IP/LAN/локальный адрес) — копирование в буфер
- Подтверждение копирования уведомлением
- `init_rsa_key()` — фоновая генерация RSA-ключа при старте приложения
- Пошаговое логирование в `log.txt` (logger.py)
- Глобальный хук непойманных исключений (`sys.excepthook`) + обработчик asyncio
- `P2PClient.is_connected()` — проверка состояния подключения
- `P2PManager.cleanup_voice()`, `get_room_code()` — новые методы фасада

### Изменено
- P2PManager реорганизован в фасад — вся логика вынесена в `P2PHost`, `P2PClient`, `VoiceController`
- SessionCreator: IP хоста получается асинхронно, UPnP — в фоне, добавлен `find_local_port()` и `setup_upnp()`
- Основное окно: новое расположение полей ввода (код сессии + IP:Port), кнопка "Отключиться"
- Чат: HTML-рендер с выравниванием своих сообщений вправо, поддержка смены ника/аватара в истории
- Аватар: добавлен `make_round_b64()`, поддержка PyInstaller (`sys._MEIPASS`) во всех путях к ресурсам
- `closeEvent` — асинхронная очистка с флагом `_closing`, предотвращает краш при закрытии
- `warmup()` делает `pass` — убран запуск/остановка аудиоустройства при старте
- Микрофон включается только после подключения к сессии

### Исправлено
- Краш voice-колбэков в потоке PortAudio — все колбэки обёрнуты в `try/except`
- `_output_callback` использует `outdata[:, 0] = arr` вместо `np.array(arr).reshape(-1,1)` — устранён крах numpy в C-слое
- SessionCreator: `get_host_ip()` больше не крашит сессию при таймауте (возвращает `""`)
- Иконка установщика — PNG заменён на ICO (Inno Setup)

## alpha 0.2 (2026-07-12)

### Исправлено
- Зависание при подключении при неизвестном ответе от хоста — добавлена обработка `else` в `P2PManager.connect()`

- Кнопка "Подключиться" оставалась заблокированной при ошибке — `_on_connection_failed()` восстанавливает её состояние
- Сборка PyInstaller не запускалась — добавлен корректный путь к `qwindows.dll` через `QT_QPA_PLATFORM_PLUGIN_PATH`
- `logging.basicConfig` отсутствовал в `main.py` — добавлен

### Добавлено
