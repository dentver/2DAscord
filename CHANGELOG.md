# Changelog

## alpha 0.2 (2026-07-12)

### Исправлено
- Зависание при подключении при неизвестном ответе от хоста — добавлена обработка `else` в `P2PManager.connect()`
- Окно подключения не закрывалось после успешного коннекта — `_on_welcome_received()` теперь вызывает `_hide_join_frame()`
- Кнопка "Подключиться" оставалась заблокированной при ошибке — `_on_connection_failed()` восстанавливает её состояние
- Сборка PyInstaller не запускалась — добавлен корректный путь к `qwindows.dll` через `QT_QPA_PLATFORM_PLUGIN_PATH`
- `logging.basicConfig` отсутствовал в `main.py` — добавлен

### Добавлено
- README, CHANGELOG, API-документация
- Комментарии в исходном коде

### Изменено
- Установщик переведён на `--onefile` + Inno Setup (37.5 MB, LZMA2/max)
- Английская и русская локализация установщика

## alpha 0.1 (2026-07-10)

### Добавлено
- Первая сборка (`--onedir` + Inno Setup)
- P2P-чат (текст, аватары, ники)
- UPnP проброс портов
- Тёмная тема (CSS)
- Голосовая связь (заготовка)
